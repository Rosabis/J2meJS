### 网络部署与开源义务

J2meJS 是一个纯客户端应用。浏览器会把完整的程序和应用数据下载到本地存储（包括 IndexedDB），所有代码都在用户自己的设备上执行，服务器端不运行任何程序代码。

因此，将**修改后**的版本部署到任何 Web 服务器或网络服务上，都会向每一位访问者交付一份完整、可运行的副本，这构成 GNU 通用公共许可证第 2 版意义上的**分发**。根据该许可证第 2(b) 条与第 3 条的要求，如果您分发修改版，就必须向每一位接收者免费提供修改版的完整对应源码。这只是对许可证既有条款的重申，并非附加限制。

把修改版托管在服务器上、或让其数据存放在 IndexedDB 中，都**不能**免除这一义务。
